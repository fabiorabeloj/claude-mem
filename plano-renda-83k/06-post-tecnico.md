# Modelo Universal de Artigo Técnico (em inglês)

Objetivo: 2 posts/mês que provem competência e apareçam quando alguém pesquisar seu nome. Um bom post técnico vale mais que 200 applications — recrutadores e clientes chegam por ele durante anos.

## Fórmula do título (escolha uma)

- **Problema resolvido:** "How I `[RESULTADO]` with `[TECNOLOGIA]`" — ex.: *How I gave Claude Code persistent memory across sessions*
- **Lição cara:** "What I learned building `[COISA]` (`[NÚMERO]` `[MÉTRICA]` later)"
- **Contraponto:** "You probably don't need `[COISA POPULAR]` for `[PROBLEMA]`"
- **Bastidores com números:** "`[PROJETO]`: architecture, mistakes, and numbers"

## Estrutura (800–1500 palavras — mais que isso, corte)

```
1. O GANCHO (2–3 frases)
   O problema real, em linguagem direta. Por que dói. Nada de "In today's world of AI...".

2. CONTEXTO MÍNIMO (1 parágrafo)
   Só o necessário para entender a solução. Link para o resto.

3. A SOLUÇÃO (60% do post)
   - Arquitetura/abordagem com UM diagrama ou snippet por conceito
   - O trade-off que você escolheu e POR QUÊ (é isso que separa senior de junior)
   - O que NÃO funcionou antes de funcionar (a parte mais lida do post)

4. RESULTADOS (números)
   Antes/depois: latência, custo, usuários, linhas removidas — qualquer métrica honesta.

5. FECHAMENTO (3 frases)
   O que você faria diferente + link do projeto + 1 pergunta aberta para gerar comentários.
```

## Checklist antes de publicar

- [ ] Título passaria no teste "eu clicaria?" (mostre a 1 pessoa antes)
- [ ] Primeiro parágrafo sem clichê de IA ("game-changer", "revolutionize", "in the era of")
- [ ] Todo snippet de código roda (copie do repositório real, não escreva de memória)
- [ ] 1 diagrama ou imagem no primeiro terço
- [ ] Link para o projeto/GitHub aparece no mínimo 2 vezes
- [ ] Bio de 1 linha no rodapé com CTA: "I help `[PÚBLICO]` `[RESULTADO]` — reach me at `[CONTATO]`"

## Distribuição (o post não se divulga sozinho)

| Canal | Formato | Quando |
|-------|---------|--------|
| Blog próprio / dev.to | Post completo | Dia 0 |
| X/Twitter | Thread de 5–8 tweets (gancho + 1 insight por tweet + link no fim) | Dia 0 |
| LinkedIn | Resumo de 200 palavras em PT ou EN + link nos comentários | Dia 1 |
| Hacker News / Reddit (r/programming, r/LocalLLaMA etc.) | Título direto, sem marketing | Dia 2, horário de pico US |
| Newsletter/comunidades do nicho | Sugerir para curadores | Semana 1 |
