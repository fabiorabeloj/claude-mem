# Kit de Modelos Universais — Meta: R$ 83 mil/mês

Modelos prontos para executar os três caminhos do plano (emprego internacional, consultoria de IA, produto). Todos usam placeholders no formato `[ASSIM]` — preencha e use. São "universais" porque funcionam para qualquer cliente, vaga ou nicho: você só troca os placeholders, nunca a estrutura.

## Índice

| Arquivo | O que é | Quando usar |
|---------|---------|-------------|
| `01-posicionamento.md` | Bio, headline e pitch pessoal (PT + EN) | Antes de tudo — é a base dos demais |
| `02-outreach.md` | E-mails e DMs frias (vagas e clientes) | Fase de prospecção, toda semana |
| `03-proposta-consultoria.md` | Proposta comercial de projeto fechado | Após a primeira call com um lead |
| `04-precificacao.md` | Tabela de preços e regras de escopo | Ao montar qualquer proposta |
| `05-follow-up.md` | Sequências de follow-up (3 toques) | 3, 7 e 14 dias após qualquer contato |
| `06-post-tecnico.md` | Estrutura de artigo técnico em inglês | 2x/mês para construir autoridade |
| `07-curriculo-us.md` | Currículo padrão americano (1 página) | Aplicações para vagas remotas US |
| `08-pipeline-semanal.md` | Rotina semanal + rastreador de pipeline | Toda segunda-feira |
| `09-cestos-de-ovos.md` | Diversificação de fontes de renda (5 cestos) | Revisão trimestral da estratégia |

## Regra de ouro

Nenhum modelo funciona sem volume e consistência. Os números mínimos semanais estão no `08-pipeline-semanal.md` — se a semana fechou abaixo deles, o problema não é o modelo.
